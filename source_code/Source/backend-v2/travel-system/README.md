
# Travel System - Microservices Project

## Services & Ports
- api-gateway: `http://localhost:8080` (main)
- user-service: `http://localhost:8081`
- tour-service: `http://localhost:8082`
- guide-service: `http://localhost:8083`
- recommendation-service (Python Flask): `http://localhost:5000`

## Run with Docker Compose
```bash
docker-compose up --build
```
